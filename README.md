# Real-Time Face Detection Website

This is a simple real-time face detection website made with Flask, OpenCV, MediaPipe, HTML, CSS, and vanilla JavaScript.

The project uses your webcam, sends the video through Flask, detects faces with MediaPipe, and draws a green box, confidence score, and center point on each detected face.

## Features

- Real-time webcam face detection
- Multiple face detection support
- FPS counter
- Detection confidence percentage
- Live face counter
- Camera status badge
- Capture image button
- Responsive blue and white dashboard design
- Simple beginner-friendly code
